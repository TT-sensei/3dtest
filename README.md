# ナビキャラと ちいさな3Dのまち

TT-senseiのthree.js初作品。ナビキャラと一緒に、かわいい小さな町を歩いて探検するプロトタイプです。

## 操作
- PC：WASD または矢印キーで移動
- タブレット：画面下の方向ボタンで移動
- 「ナビキャラをかえる」で6人を切り替え
- 「まわりをみる」で向きを変更

## たんけんのしくみ
- 案内板やナビキャラの近くまで歩くと、ヒントが表示されます。
- 「ここを はっけん！」を押すと、見つけた場所やキャラクターを探検ノートに記録します。
- 記録はブラウザのlocalStorageに保存され、同じ端末・ブラウザで続きから遊べます。
- 探検ノートは10項目。リセット機能はあえて設けていません（ブラウザのサイトデータを消すと記録も消えます）。

## 技術
- 静的HTML / CSS / JavaScript
- Three.js r150の単体ビルドを `vendor/three.min.js` に同梱し、モジュール読み込みの待機問題を回避
- APIキー、バックエンド、ビルド工程なし
- ナビキャラ素材は `TT-sensei/navi-character-` のWeb用画像を参照。素材デザインは改変せず2Dスプライトとして使用

## 起動
GitHub Pagesで公開するか、ローカルサーバーから `index.html` を開いてください。

## オフライン対応
Three.jsはローカルですが、ナビキャラ画像はGitHubから読み込むため、現在は完全オフラインではありません。必要な画像をこのリポジトリ内に同梱し、通信なしで動くことを次段階で確認します。
